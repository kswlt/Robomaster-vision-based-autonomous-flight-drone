## 阶段5：根因定论与修复验证（2026-09-23）

### 决定性实验：IR 散斑关闭（laser OFF）

录制 `/home/orangepi/vio_data/20260922T235522Z_LASEROFF3/bag`（64.4s，IMU 195Hz；动作段：静止0-15s → yaw/旋转 15-45s → 平移运动 45-65s；laser_power=0 关闭红外投射器）。
回放配置：-0.8° 外参 + 848 内参 + ts=+0.001256（与 DYN50E 实验完全相同，唯一变量：IR laser ON/OFF）。

**对比结果**：

| 指标 | laser ON (DYN50E) | laser OFF (LASEROFF3) |
|---|---|---|
| 全程最大 |p| | **494 m（爆炸）** | **0.65 m** |
| 运动后终点 |p| | 爆炸不收敛 | **0.19 m（闭合回原点）** |
| 旋转/平移段 | yaw 0.24 / pitch 1.84 / 平移 12.8 m | 全部有界 ≤ 0.65 m |
| 运动后静止 | 420-494 m 持续爆炸 | 收敛 |
| ba | 运动后 ba_x→0.05-0.1 | ba_y→0.05（有界） |
| 特征数 | 58-74 | 54-61 |

**结论：IR 散斑（红外投射器散斑图案）是动态漂移根因。**

机制：D430 红外投射器默认开启（rs_launch.py 默认参数），投影散斑图案**附着在物体表面、随深度变化**。设备平移时：
- 每个物体深度变化 → 散斑图案改变 → 特征点"移动"（非真实世界特征位移）→ 误匹配
- 视差/深度误判 → 位置放大（平移段 12.8m vs 真实 0.5m，~25x）
- 误匹配累积 → 特征池污染 → 运动后视觉更新失效 → 纯 IMU 积分 + 残余姿态误差 → 长静止持续爆炸（494m）
纯旋转（深度不变）时散斑图案稳定 → 误差有界（yaw 0.24m / pitch 1.84m）。

### 修复
1. **关闭红外投射器**：`enable_ir_emitter:=false`（launch 参数），已写入 `start_vio.sh`、`run_vio.sh`；运行时等价 `depth_module.laser_power:=0`（本次实验已用 laser_power=0 验证）。
   - 注意：laser OFF 后图像变暗（mean 95→32），特征数下降（74→61），但**仍足够**（54-61 features，ZUPT 328 次 passed）。
   - 若暗场景特征不足，可增大 `depth_module.exposure/gain` 或 `fast_threshold`（后续按需）。
2. 保留 848 内参修正（422.216, 422.216, 423.231, 240.207；resolution 848x480；0 畸变）。
3. 外参维持 Sep19 -0.8°（laser OFF 下全程有界；历史 -7° 标定在 640 环境，方向语义待后续统一）。
4. 遗留次要缺陷（非漂移主因，建议后续修复）：bridge 时钟下包络单调漂移 -0.9ms/s（改为滑动窗口均值/中位数）；start_vio.sh 仍引用 640 profile 旧段（848 实际生效段在 run_vio.sh）。
