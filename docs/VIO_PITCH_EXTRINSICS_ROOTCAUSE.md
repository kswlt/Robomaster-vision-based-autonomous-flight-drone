# VIO 静止/晃动漂移根因分析：相机-IMU Pitch 外参安装角误差

日期：2026-09-14
状态：**静止根因已定位并修复验证；动态晃动/飞行待验证（NOT VERIFIED IN FLIGHT）**

## 1. 症状

- 飞机完全静止放置时，OpenVINS 估计姿态 pitch 从 ~0.3° **单调漂移到 +7°**，加速度偏置 `ba_x` 从 0 **单调增长到 +1.15 m/s²**（约 0.12 g），两者高度同步。
- roll 基本稳定；位置靠 ZUPT（零速更新）勉强压住（静止漂移 2~3 m）。
- **一旦手持晃动/快速运动，ZUPT 失效，错误的加速度偏置立刻进入二次积分，位置在几十秒内爆炸（几十~几百米），即"一动就飘"。**
- 此前多轮调参（特征点数、fast 阈值、跟踪频率、ZUPT 阈值、IMU 噪声/随机游走、timeoffset、在线标定）均无法根治。

## 2. 根因（已通过受控实验确认）

**D430 相机相对于飞控 IMU 实际下倾约 7° 安装，但 `kalibr_imucam_chain.yaml` 外参假设相机与 IMU 完全水平（R_IC = [0,0,1; -1,0,0; 0,-1,0]）。**

静止水平时：
- IMU 重力方向要求机体 pitch = 0°；
- 视觉因相机真实下倾，要求机体 pitch ≈ +7° 才能解释图像；
- 滤波器无法同时满足两者，把这 ~7° 的系统性方向冲突吸收进**加速度偏置 ba_x**（稳态 ≈ g·sin7° ≈ +1.2 m/s²）和**姿态 pitch**（≈ +7°）。
- 静止时 ZUPT 把速度强制清零，掩盖了错误偏置；一旦运动，ZUPT 不触发，错误 ba_x 直接积分成速度、再积分成位置 → 发散。

### 为什么在线标定无法自动修正

`ov_msckf/src/state/State.cpp` 中外参在线标定的初始旋转协方差标准差仅 **0.005 rad ≈ 0.29°**（平移 0.015 m）。实际误差 7° 是先验的约 24 倍，滤波器先验强烈认为外参准确，拒绝大幅修正，因此开启 `calib_cam_extrinsics` 也无法收敛（此前实验已证实会发散）。

## 3. 证据链

1. 静止日志（ZUPT passed 15558 / failed 0，飞机真实静止）：`ba_x` 0 → +1.15 单调增长，`pitch` 0.3° → +6.97° 单调增长，`ba_x/g ≈ 0.117 ≈ sin(6.7°)`，与 pitch 漂移角一致。
2. 排除 IMU/坐标转换问题：静止时 FRD→FLU 转换后 IMU `z ≈ +9.81, x/y ≈ 0`，转换正确，IMU 数据正常。
3. 受控单变量实验：仅修改外参 pitch，其余配置不动：
   - 外参 0°（水平假设）：pitch → +6.97°，ba_x → +1.15，静止漂移 2.5 m；
   - 外参补偿 **-7°（相机下倾）**：pitch 稳定 **0.32°**，ba_x 稳定 **+0.004**（隐含残余倾斜仅 0.02°），静止位置漂移 **0.02 m**。
   - 方向与角度均被实验确认。

## 4. 修复

在相机 X 轴（左右轴）方向加入 -7° pitch 补偿。Kalibr `T_imu_cam`（C→I）更新为
`R_IC_new = R_IC_old · Rx(-7°)`，两个相机相同旋转、平移不变：

```
cam0 T_imu_cam:
  [0.000000, -0.121869, 0.992546, 0.080]
  [-1.000000,  0.000000, 0.000000, 0.000]
  [0.000000, -0.992546,-0.121869, 0.000]
  [0,0,0,1]
cam1 T_imu_cam:
  [0.000000, -0.121869, 0.992546, 0.080]
  [-1.000000,  0.000000, 0.000000,-0.050]
  [0.000000, -0.992546,-0.121869, 0.000]
  [0,0,0,1]
```

补偿后相机光轴在 IMU 系为 `[0.9925, 0, -0.1219]`（水平向前、略向下 7°）。
名义水平外参备份在运行时 `config/d430/kalibr_imucam_chain.nominal.yaml`。
辅助工具：`scripts/apply_extrinsics.py <alpha_deg>`（负=下倾）、`scripts/analyze_attitude.py`（解析姿态/偏置演化）。

同时：
- `calib_cam_extrinsics / calib_cam_intrinsics / calib_cam_timeoffset` 均设为 `false`（固定外参/内参/时间偏移，避免在线标定在大残差下发散）；
- `timeshift_cam_imu` 固定为 `-0.011`；
- estimator 跟踪/ZUPT 参数**回退到原始基线值**（num_pts=100, fast_threshold=20, track_frequency=21, max_msckf_in_update=25, zupt_chi2_multipler=0, zupt_max_velocity=0.1, init_max_disparity=10）。
  - 注意：曾一次性叠加 num_pts=200 / zupt_chi2_multipler=0.5 / max_msckf_in_update=75 等 9 项调参，外参修正后反而出现 yaw 漂移与姿态跳变，已回退。**外参正确后不应再沿用为补偿外参错误而做的调参。**

## 5. 验证结果

静止（约 75 s，单次上电）：

| 指标 | 修复前(外参0°) | 修复后(外参-7°) |
| --- | --- | --- |
| pitch | 漂移 +6.97° | 稳定 0.32°（范围 0.16~0.32°） |
| roll | 稳定 | 稳定 -0.49° |
| ba_x | +1.15 m/s² | +0.004 m/s² |
| 隐含残余倾斜 | 6.7° | 0.02° |
| 静止位置漂移 | 2.5 m | 0.02 m |

## 6. 待办与建议

1. 【现场】手持做平移 + 快速旋转激励，用 `scripts/analyze_attitude.py` 确认 ba/pitch/位置在运动中保持有界、回正后不发散。
2. -7° 为手动测量补偿（残余 ~0.02~0.3°，已足够 VIO 工作）。精确值建议后续用 Kalibr 标定板做一次 cam-IMU 外参离线标定；或在把 State.cpp 外参旋转初始协方差从 0.005 增大到 ~0.1 rad 后，仅开启外参在线标定做精修（需改源码重编）。
3. 动态稳定后再评估是否需要恢复"更多特征点"等前端调参（应在正确外参基础上单独、逐项验证，不要一次性叠加）。
4. 动态/飞行通过前，Depth / 2D Map / A* / Path Follower 阶段继续暂停。
